# 自媒体短视频需求模板（中文标准版）

> 用法：复制下面整段，把 `【填】` 的地方改成你的情况，发给 Agent。带 ★ 的是必填，其余留空就按默认走。
> 填得越全，Agent 需要回头问你的次数越少。拿不准的写「不确定」，不要编。

---

## 0. 使用说明（发给 Agent 前不用改）

你收到这份需求后，按以下顺序执行：

1. 先做**环境自检**：`python run.py --check`，把缺的东西列给我。
2. 再**核算价格**：所有花钱环节，去厂商官网查当前单价，列明细表（项目 / 单价 / 每条消耗 / 每月预估 / 官网链接）。核实不了写「未核实」，不许估算，不许引用旧价。
3. 预算超了先说，**不要先跑**。
4. 信息不足时，**一次把要问的问题列完**，不要边做边问。
5. 正式出片前，先给我一条**样例**确认风格，再批量。

## 1. 账号与定位

- ★ 一句话定位：`【填：我帮谁，解决什么问题，用什么方式】`
- ★ 目标平台（可多选）：`【抖音 / 小红书 / B站 / 视频号 / X】`
- 账号阶段：`【全新号（0 粉丝）/ 已有粉丝 ___ / 有存量内容 ___ 条】`

- 人设关键词（3 个）：`【填】`
- 不做的事（排除项）：`【填：比如不卖课、不做直播、不接广告】`

## 2. 目标人群与变现

- 我希望观众看完做的动作：`【私信 / 评论 / 进群 / 只记住我】`


## 4. 参考账号

- 想对标 2–3 个账号（不用真名，描述风格也行）：`【填】`

## 5. 生产条件

- ★ 录制方式：`【真人口播 / 录屏讲解 / 图文轮播 / 混合】`
- 是否出镜：`【出镜 / 不出镜】`
- 拍摄设备：`【手机 / 相机 / 电脑摄像头】`

- 素材来源：`【自己拍 / 素材库 / AI 生成 / 混合】`
- 有没有现成素材库：`【有，路径 ___ / 没有】`

## 6. 输出规格

- ★ 单条时长：`【60–90 秒 / 3 分钟 / 5 分钟】`

- 字幕：`【有 / 无】｜样式：`【大字居中 / 底部常规 / 关键词描色】`
- 配音：`【真人原声 / AI 配音 / 不要配音只要字幕】`
- BGM：`【要 / 不要】｜风格：`【填】`
- 封面：`【要 / 不要】｜风格：`【填：比如大字 + 纯色底】`
- 画面调性：`【干净简约 / 强对比 / 商务感 / 生活感】`
- 片头片尾：`【要 / 不要】｜时长上限：`【___ 秒】`

## 7. 平台与发布

- ★ 要适配的平台：`【抖音 / 小红书 / B站 / 视频号 / X】`
- 各平台账号状态：`【已注册 / 未注册】`
